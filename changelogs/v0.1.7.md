# v0.1.7 - 2026-07-03

## Markdown-Based Version Changelogs & UI Upgrades

TraceNest now features a robust, Markdown-based changelog system directly integrated into the UI.

### Highlights
- **Markdown Changelogs:** Release notes are now written in standard Markdown files stored in the `changelogs/` folder.
- **Dynamic Versions Modal:** Rebuilt the 'Versions' UI modal to feature a beautiful two-pane layout. It dynamically fetches and renders markdown using `marked.js`.
- **PyPI Documentation Sync:** The main project `README.md` is now automatically synced with the full project changelog to ensure release notes are visible directly on PyPI.
- **Improved UI Links:** Added proper developer attribution linking back to GitHub in the UI footer.
- **Obsolete Files Cleaned:** Removed the static `changelog.json` in favor of the dynamic API.
