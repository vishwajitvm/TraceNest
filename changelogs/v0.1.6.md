# v0.1.6 - 2026-07-03

## Secret Redaction & Masking

TraceNest now includes a built-in secret redaction and credential masking engine to prevent sensitive data from leaking into logs or being exposed via the UI.

### Architecture
Redaction is applied at two distinct layers for defense-in-depth:
1. **Write Path:** Redacts log entries (strings, dictionaries, lists) before writing to disk.
2. **Read Path:** Redacts text again when read from disk via the UI endpoint.

### Highlights
- Added built-in secret redaction to prevent credentials, tokens, and keys from leaking in logs.
- Added recursive masking for dictionaries, lists, request data, and response data.
- Added pattern-based masking for raw log strings, DB URLs, and Authorization headers.
- Logs are now redacted before storage and before UI display for defense-in-depth safety.
- Added configuration options for custom sensitive keys and redaction mask.
